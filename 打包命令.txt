AtlasWorks x86 打包 / 导出 / 启动命令

说明：
1. 只打 amd64 / x86_64 单架构镜像，不使用 buildx。
2. 默认外部数据库版使用 docker-compose.yml。
3. 内置 PostgreSQL 15 版使用 docker-compose.yml + docker-compose.pg15.yml。


首次准备 amd64 基础镜像：
docker pull --platform linux/amd64 debian:bullseye
docker tag debian:bullseye debian:bullseye-amd64


1. 前端打包
cd /d D:\map\atlasWorks\frontend
npm run build


2. 镜像打包
cd /d D:\map\atlasWorks
docker build --pull=false --progress=plain -t atlasworks:release-2.1.0 -f deploy/docker/Dockerfile .


3. 导出镜像
docker save -o atlasworks-release-2.1.0-amd64.tar atlasworks:release-2.1.0


4A. 启动：连接外部 PostgreSQL
docker compose -f docker-compose.yml -f docker-compose.external-db.yml up -d --no-build --force-recreate


4B. 启动：使用内置 PostgreSQL 15
docker compose -f docker-compose.yml -f docker-compose.pg15.yml up -d --no-build --force-recreate


5. 查看状态
docker compose ps
curl.exe -s http://127.0.0.1:18000/api/health
curl.exe -s http://127.0.0.1:18001/api/health


6. 停止
docker compose -f docker-compose.yml -f docker-compose.external-db.yml down

内置 PostgreSQL 15 版停止：
docker compose -f docker-compose.yml -f docker-compose.pg15.yml down
