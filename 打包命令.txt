AtlasWorks x86 打包 / 导出 / 启动命令

说明：
1. 只打 amd64 / x86_64 单架构镜像，不使用 buildx。
2. 外部数据库版使用 docker-compose.external-db.yml。
3. 内置 PostgreSQL 15 版使用 docker-compose.pg15.yml。
4. 常规部署只需要改数据库连接、端口、数据目录、瓦片目录、CPU、内存。
5. ATLASWORKS_WORKERS 是 API Web 进程数，不是切片 Worker 数量；切片并发按 worker 容器拆分，目前默认每种切片类型 1 个容器。


首次准备 amd64 基础镜像：
docker pull --platform linux/amd64 debian:bullseye
docker tag debian:bullseye debian:bullseye-amd64


1. 前端打包
cd /d D:\map\atlasWorks\frontend
npm run build


2. 镜像打包
cd /d D:\map\atlasWorks
docker build --pull=false --progress=plain -t atlasworks:release-20260506 -f deploy/docker/Dockerfile .


3. 导出镜像
docker save -o atlasworks-release-20260506.tar atlasworks:release-20260506


4A. 启动：连接外部 PostgreSQL
docker compose -f docker-compose.external-db.yml up -d --no-build --force-recreate


4B. 启动：使用内置 PostgreSQL 15
docker compose -f docker-compose.pg15.yml up -d --no-build --force-recreate


5. 查看状态
docker compose -f docker-compose.external-db.yml ps
docker compose -f docker-compose.pg15.yml ps
curl.exe -s http://127.0.0.1:18000/api/health
curl.exe -s http://127.0.0.1:18001/api/health
curl.exe -s http://127.0.0.1:18080/health
curl.exe -s http://127.0.0.1:18002/healthz
curl.exe -s http://127.0.0.1:18002/api.html


6. 停止
docker compose -f docker-compose.external-db.yml down

内置 PostgreSQL 15 版停止：
docker compose -f docker-compose.pg15.yml down
